# 🎮 CodeBox

> A pixelated, gamified e-learning platform designed to make coding fun, interactive, and addictive.

---

## 🚀 Overview

**CodeBox** is a modern e-learning platform with a retro pixel-style UI where users learn programming through structured courses, hands-on exercises, and gamified progress tracking.

Whether you're just starting out or building consistency, CodeBox keeps you engaged with streaks, progress tracking, and a clean developer-friendly dashboard.

---

## ✨ Features

### 📚 Courses
Currently available beginner-friendly courses:
- HTML Beginner
- CSS Beginner
- Python Beginner
- React Beginner

Each course includes:
- Multiple **chapters**
- Each chapter contains multiple **interactive exercises**

---

### 🔓 Access Model

- ✅ First **2 chapters are FREE** in all courses
- 🔒 Remaining chapters require **Pro Membership**
- 🎁 Users get a **7-day free Pro trial**

---

### 🧑‍💻 Learning Experience

- Interactive coding environment powered by **Sandpack**
- Hands-on exercises for every chapter
- Learn-by-doing approach instead of passive reading

---

### 📊 Dashboard

A clean and minimal dashboard to track:

- 📈 Progress across courses
- 📘 Enrolled courses
- ✅ Solved exercises
- 🔥 Daily streak

---

### 🎮 Gamified UI

- Pixel-inspired design
- Smooth animations
- Engaging and rewarding learning experience

---

## 🛠️ Tech Stack

### ⚙️ Frontend
- **Next.js** – Fullstack React framework
- **Tailwind CSS** – Utility-first styling
- **shadcn/ui** – Modern UI components
- **Framer Motion** – Animations & transitions

---

### 🔐 Authentication & Payments
- **Clerk**
  - User authentication
  - Subscription management
  - Pro membership handling

---

### 🗄️ Backend & Database
- **NeonDB** – Serverless Postgres database
- **Drizzle ORM** – Type-safe database queries

---

### 🧪 Developer Tools
- **Sandpack** – In-browser coding IDE
- **ImageKit** – Optimized image delivery

---

## 🧠 Core Concepts

- Course-based structured learning
- Progressive unlocking (Free → Pro)
- Gamification (streaks, progress tracking)
- Real coding practice (not just theory)
